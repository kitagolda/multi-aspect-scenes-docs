Group 11 — Structural: Larger Subtree Divergence (≥4 Nodes)

Count
21 landscape groups (1.6% of 1,347)
Difficulty
Hard / Fallback
Target outcome
Keep separate .tsx variants via the lazy @TsxScene proximity AR map by default; selectively unify localized subtrees or strip copy-paste artist bloat during manual feature migration.

#1. What Defines This Group

Landscape variants diverge structurally by 4 to 48 nodes — adding or removing entire subtrees, wrapping root hierarchies differently, or carrying extra masks/effects/controls on specific aspect ratios.

Even inside this hardest group, inspecting the real WBIP trees shows that most divergences are surprisingly localized (a single added sub-panel, a wide-screen side cover, or duplicated sound containers), rather than completely different scenes from top to bottom.

#3. Potential Solution (Lazy Fallback + Selective Refactoring)

Attempting to auto-merge these 11 groups in wbip-processor is not worth the complexity or regression risk (they represent only 2.4% of landscape groups).

  1. Default — Lazy @TsxScene AR import map (tsx-aspect-lookup):
    • Emit separate .tsx files only for the distinct structural variants (e.g. for PlayersProfile.Popup, only 2 files are needed: one for 4x3–16x9 and one for 18x9–19.5x9, NOT 6!).
    • Bind them with the parameterized @TsxScene AR map so the browser downloads only the 1 winning aspect chunk by screen proximity:
TS 
// Only 2 distinct TSX modules needed for PlayersProfile.Popup (instead of 6):
@TsxScene("PlayersProfile.Popup/scene@.object", {
    "3x2": () => import("./tsx/scene3x2.object"),   // covers 4x3, 3x2, 5x3, 16x9 via proximity
    "18x9": () => import("./tsx/scene18x9.object"), // covers 18x9, 19.5x9 via proximity
})
  1. Optional manual cleanup during feature migration:
    • Once a team actively migrates one of these 11 features to prefabs, several can trivially become 1 .tsx by hand:
    • AlbumStoneBooster.Arena: delete the 5 stray legacy sound nodes on 4x3.
    • PlayersProfile.Popup: keep #Covering in a single .tsx with Hidden={byAspect({ "18x9": false, "19.5x9": false, default: true })}.
    • Panels.Top: verify whether the 2nd MULTI_MASK_TEXTURE_NODE on 3x2 is even needed.
