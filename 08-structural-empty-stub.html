Group 08 — Structural: Empty / Stub Variant

Count
1 landscape group (0.1% of 1,347)
Difficulty
Easy
Target outcome
Collapse to 1 scene.object.tsx that hides the 4x3-only filler sprites on wider aspects.

#1. What Defines This Group

One aspect variant contains real display content, while another aspect variant is an empty 1-node root stub (0 children, 0 states, 0 actions).

Across all 5,978 WBIP packages in the corpus, this occurs in only 1 legacy package — static-Panels.BottomInSlot (the bonus-game iPad letterbox bar)!

#2. Real WBIP Examples (Side-by-Side Trees)

#static-Panels.BottomInSlot — sceneBonusGamePanel@.object

On 4x3 (3 nodes — renders the iPad bottom black panel & logo):
RENDER_STATES_NODE (idx:2) — pos=(0.0, 1.0)
  ├─ SPRITE_NODE (idx:0) — pos=(45.0, 534.0), sprite="ipad black panel.spr"
  └─ SPRITE_NODE (idx:1) — pos=(409.0, 565.0), sprite="ipad black panel logo.spr"
On 3x2 (1 node — intentionally empty stub):
RENDER_STATES_NODE (idx:0) — pos=(0.0, 1.0)
  (no children)

(The pvr16-static-Panels.BottomInSlot copy is identical, scaled for 854×480 coordinates: (34, 400) and (307, 424).)

#3. Potential Solution (Reduce to 1 Scene)

Because there are zero FSM states or actions (0 / 0 / 0), there is no flatIndex conflict at all. Collapse directly into 1 scene.object.tsx that sets Hidden={true} on the two iPad sprites whenever the active aspect is not 4x3:

TSX 
export const sceneName = "sceneBonusGamePanel4x3.object";

export function build(contentManager: IContentManager, prefabData: IPrefabData): GameComponent {
    const hideIpadPanel = byAspect({ "4x3": false, default: true });

    return (
        <RenderStatesNode Position={{ x: 0, y: 1 }}>
            <SpriteNode
                Position={{ x: 45, y: 534 }}
                SpriteName="ipad black panel.spr"
                Hidden={hideIpadPanel}
            />
            <SpriteNode
                Position={{ x: 409, y: 565 }}
                SpriteName="ipad black panel logo.spr"
                Hidden={hideIpadPanel}
            />
        </RenderStatesNode>
    );
}

#Edge cases & gotchas

  • Make sure sceneBonusGamePanel3x2 isn't being inspected for children.length === 0 in legacy code-behind; if anything checks child count rather than visibility, conditional rendering (!hideIpadPanel && (...)) works cleanly here too because there is no FSM.
