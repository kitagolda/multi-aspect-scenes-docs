Group 10 — Structural: Small Node Delta (1–3 Nodes)

Count
55 landscape groups (4.1% of 1,347)
Difficulty
Hard
Target outcome
Collapse via union tree + Hidden toggle (or strip stray dead nodes) into 1 scene.object.tsx, OR fall back to the lazy @TsxScene AR map where FSM bindings diverge.

#1. What Defines This Group

Every landscape variant shares the same core scene tree, except one or more aspects add or remove 1 to 3 minor nodes — typically:

  • An extra decorative SPRITE_NODE (e.g. a border divider or subtle glow only present on wide or narrow screens),
  • An extra SOUND_NODE or button sub-container,
  • A stray empty artist placeholder left behind on one aspect (e.g. CONTAINER_NODE [id="tempObj"] with 0 children!).

Because even a single inserted node shifts flatIndices for all subsequent nodes in the scene, the two variants cannot blindly share a WbipSceneV3 without re-indexing or normalizing the tree.

#3. Potential Solution (Reduce to 1 Scene vs. Fallback)

Choose between two clean paths depending on whether the extra 1–3 nodes are stray/dead or intentionally visible:

  1. Path A — Drop dead/stray nodes (e.g. tempObj in LevelMap.Popups):
    • If the extra node has 0 children, no visual/sound component, and is unreferenced by FSM or code-behind, discard it during migration and collapse to the clean 77-node canonical scene (dropping the scene down into Group 01–05!).
  2. Path B — Union tree in 1 scene.object.tsx with Hidden toggle (e.g. NavigationBarVer2, ClanChestsItemVer2):
    • Keep the union tree (the 27-node or 73-node superset) as the single canonical scene.object.tsx and its single WbipSceneV3.
    • Hide the 1–3 aspect-specific nodes on aspects where they did not exist (Hidden={byAspect({ "4x3": true, "5x3": true, "16x9": true, default: false })}).
    • Because all nodes stay present in the tree, flatIndices never shift across aspects!
  3. Path C — Zero-risk fallback (@TsxScene lazy AR map):
    • If the extra nodes have complex aspect-specific FSM animations or code-behind expectations (e.g. BottomBarInSlotFacelift with 370–373 nodes), keep separate .tsx variants bound via the lazy proximity @TsxScene AR map until that feature is refactored manually.
TSX 
// Path B: Union tree in 1 scene.object.tsx for Clans.NavigationBarVer2
export const sceneName = "sceneNavigationBar3x2.object";

export function build(contentManager: IContentManager, prefabData: IPrefabData): GameComponent {
    return (
        <ControlNode Id="navigationBarContainer">
            <TileNode /* ... */ />
            <SpriteNode
                /* Present in union tree so flatIndices stay stable across all 6 aspects */
                Hidden={byAspect({ "4x3": true, "5x3": true, "16x9": true, default: false })}
            />
            <ControlNode Id="navigationBarHolder" /* ... */ />
        </ControlNode>
    );
}

#Edge cases & gotchas

  • SOUND_NODE cannot be silenced by Hidden={true} alone: If an extra node is a SOUND_NODE, check whether any FSM action plays it — otherwise remove the dead sound node or gate its action.
  • LinearLayoutGroupNode children: Adding a hidden child inside a layout group may still reserve layout spacing unless the layout group ignores visible === false children; verify layout behavior before using Path B inside a layout container.
