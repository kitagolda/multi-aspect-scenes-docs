Multi-Aspect WBIP Scenes (scene@.object) — Diff Groups & Single-TSX Reduction Guide

This multi-page reference breaks down every multi-aspect scene@.object group found across Slotomania's local WBIP corpus into 12 focused diff groups, ordered from easiest to collapse (identical scenes requiring zero runtime logic) to hardest (structural subtree divergence and Portrait/Landscape orientation splits).

Each group page provides:

  1. What defines the group and why Flash/WBIP exports produce it.
  2. Real side-by-side WBIP examples (node trees, property values, or FSM actions/states across aspects).
  3. Reduction strategy to collapse the group into a single scene.object.tsx (or when to fall back to lazy @TsxScene aspect lookup).
  4. Complete scene inventory listing every matching package and scene@.object pattern in the corpus.

#Shared Runtime Contract (Required Even for 1 Collapsed .tsx)

Even when all aspect variants collapse into a single scene.object.tsx, two runtime seams still probe aspect-suffixed names:

  1. ScenePathResolver → MultiPathSceneFactory (slotomania-ts): probes scene4x3.object, scene3x2.object, scene16x9.object, etc., in ScreenSettings.supportedAspectTypesByProximity order.
  2. SceneBuilder.buildScene (@playtika/pixi): resolves tsxModule for the probed sceneName, then looks up resource.data.scenesV3.get(resolvedSceneName) inside package.prefab to bind FSM states, actions, rules, transitions, and flatIndices.

The tsx-aspect-lookup foundation enables both single-.tsx collapsing and multi-.tsx fallback cleanly:

  • Canonical sceneName export: TsxSceneModule exports export const sceneName = "scene3x2.object"; so SceneBuilder binds FSM data via resource.data.scenesV3.get(tsxModule.sceneName ?? sceneName) even when probed under another aspect name.
  • Lazy proximity lookup: setTsxSceneAspectResolver + selectTsxSceneForPattern / selectTsxSceneNamesToLoad ensure only the single closest aspect module is downloaded for any uncollapsed multi-.tsx group (Groups 10, 11, and structural Portrait splits).
